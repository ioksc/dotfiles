## Archivos Incluidos
* **`bashrc`:** Configuraciones para el archivo `bashrc`.
* **`xinitrc`:** Configuraciones para el archivo `xinitrc`.
* **`alacritty`:** Configuración para la terminal [Alacritty](https://alacritty.org/).
* **`vim`:** Configuraciones para el editor de texto `vim`.
* **`htop`:** Configuraciones para el `htop`.
* **`i3`:** Configuraciones para el gestor de ventanas [i3](https://i3wm.org/).
* **`i3blocks`:** Configuraciones para el `i3blocks`.
* **`rofi`:** Configuraciones para el gestor de ventanas `rofi`.
* **`starship`:** Configuraciones para el [starship](https://starship.rs/).
* **`tmux`:** Configuraciones para el `tmux`.
* **`bat`:** Configuraciones para el `bat`.
* **`xbindkeys`:** Configuraciones para el `xbindkeys`.
* **`zathura`:** Configuraciones para el `zathura`.
